# Matong Operations Suite – clickable preview

Static preview (no backend, sample data only) for Matong Energy LTD.
Screens: login, dashboard, people and HR, accounting, invoices, incoming, procurement and stock, engineering projects.

## Use his real logo
Save his logo as `assets/logo.png`. It appears automatically (a text wordmark shows until then).

## Deploy
Push to GitHub, import the repo in Vercel. No build step or settings needed.

## Edit the sample data
Everything shown lives in `data.js`.
